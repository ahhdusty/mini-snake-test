# Мини-змейка

Небольшая браузерная игра для тестирования GitHub. HTML, CSS и JavaScript без сторонних зависимостей, сборки и внешних запросов.

## Запуск

Нужен Python 3. В каталоге проекта выполните:

```sh
python -m http.server 8765 --bind 127.0.0.1
```

Откройте http://127.0.0.1:8765. Не запускайте через file://: JavaScript-модулям нужен HTTP.

## Управление

Нажмите «Начать игру». Стрелки / WASD или экранные кнопки меняют направление. Пробел и кнопка «Пауза» приостанавливают игру; «Заново» начинает новую. За яблоко начисляется одно очко, столкновение со стеной или собой завершает игру.

## Проверка

Нужен Node.js 20 или новее, установка пакетов не требуется:

```sh
node --test
```

Логика игры отделена от интерфейса в `game.js`.
